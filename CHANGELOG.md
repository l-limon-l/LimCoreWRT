# Изменения

## 2.3.3 — 2026-10-20

- Анонимная статистика: раз в сутки роутер отправляет обезличенный пинг (версия, архитектура, версия OpenWrt, режим) — без адресов серверов, подписок и трафика.
- Переключатель статистики на странице «Статус»: её можно отключить в любой момент.

## 2.3.2 — 2026-10-13

- Мультивыбор узлов: чекбоксы, выбор всех в открытой папке, групповая проверка задержки и скорости, перенос в папку и удаление с подтверждением.
- Флаги в списке узлов, обзоре и окне «Лучший узел» отображаются через локальный SVG-спрайт, независимо от emoji-шрифтов Windows и темы LuCI.
- Удалён дублирующий шрифт флагов; все изображения собраны в один файл для экономии места на роутере.

## 2.3.1 — 2026-10-10

- Ядро sing-box-extended скачивается из LimCoreWRT и проверяется по размеру и SHA-256.

## 2.3.0 — 2026-10-10

- Ядро sing-box-extended ставится из сборки LimCore с поддержкой AmneziaWG 3.1.
- Добавлены параметры AmneziaWG RandomTrailers и DisableCookies.
- Исправлено подключение к серверам AmneziaWG 3.1 с включённым RandomTrailers.
- PersistentKeepalive переносится при импорте .conf, диапазон заменяется первым числом.

## 2.2.1 — 2026-10-10

- Добавлено правило AWS: игровые серверы на Amazon (EC2, GameLift) через VPN.
- Comss.one подключается по DoH и сам следует за сменой серверов.
- Удалён Xbox DNS, заблокированный Роскомнадзором. Выбранный Xbox DNS заменяется на Comss.one.

## 2.2.0 — 2026-10-10

- Добавлены папки для своих узлов: импорт ссылок и .conf сразу в папку, перенос узла в окне «Изменить».
- Вкладки групп на обзоре можно перетаскивать, порядок сохраняется.
- Вкладка с активным узлом отмечена точкой, вкладки стали заметнее.
- На плитке узла добавлена проверка задержки одного узла.
- В режиме «Россия» без правил прокси сразу добавляется «Russia Inside», на обзоре показывается предупреждение.
- Добавлены параметры AmneziaWG 3.x.
- Исправлен запуск ядра с узлом AmneziaWG, у которого заданы J1–J3 или ITime.

## 2.1.0 — 2026-10-09

- Обновления скачиваются из файлов репозитория LimCoreWRT, а не из GitHub Releases.
- Пакеты проверяются по размеру и SHA-256 перед установкой.
- Сохранение настроек, обновление и добавление подписок больше не перезапускают firewall и DNS: ядро перечитывает конфиг без остановки.
- Если в подписке ничего не изменилось, соединение не прерывается.
- При переподключении WAN перезапускается только ядро.
